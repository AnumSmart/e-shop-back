Пет- проект.
Реализация сервера с помощью фрэймворка gin

сделано:
- логика валидации и авторизации (через JWT токены)
- Работа с базой Postgres (база подниматеся в docker через docker-compose.yml, работа с базой через бибиотеку pgx, настроен pgxpool)
- миграции для Postgres настроены через библиотеку gooose
- создан Makefile для более удобной работы
- Через docker подключён redis (в качестве "черного списка" для refresh ключей, для просроченных)
- сделана маршрутизация и группировка эндпоинтов
- реализована логика middleware
- для сервера реализован gracefull stutdown
- написаны некоторые unit-тесты
- реализованы "моки"
